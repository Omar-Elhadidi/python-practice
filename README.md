# Python Practice 🐍

A collection of Python exercises, CLI tools, and mini-projects exploring core programming, OOP, and data engineering fundamentals.

## 📂 Mini-Projects

- **`01_string_operations.py`** - String indexing, slicing, counting vowels, and f-strings.
- **`02_text_cleaner.py`** - Cleaning up messy text, removing extra spaces, and replacing shorthand words.
- **`03_grade_calculator.py`** - Grade tier calculator with 1-100 score validation.
- **`04_contact_book_cli.py`** - Terminal contact book using a dictionary with add, search, delete, and show features.
- **`05_atm_banking_cli.py`** - Simple ATM program with balance checking, deposit, and withdraw functions.
- **`06_spin_the_landmarks.py`** - Slot-machine style game that randomly matches Arabic landmarks.
- **`07_substitution_cipher.py`** - Text encryption and decryption using a shuffled character list.
- **`08_input_validator.py`** - Custom exception class and try/except validation loop for username inputs.
- **`09_oop_data_extractors.py`** - Object-oriented data extraction hierarchy using inheritance, super(), and polymorphism.
- **`10_decorator_timer.py`** - Reusable pipeline performance decorator to measure execution time.
- **`11_file_pipeline_io.py`** - File detection, CSV dictionary export, and streaming file ingestion with average calculations.
- **`12_date_countdown_calculator.py`** - Interactive countdown timer and date difference calculator using datetime and strptime.
